# 🖋️ PyTorch MNIST Classifier

A **PyTorch-based neural network** for handwritten digit classification using the [MNIST dataset](http://yann.lecun.com/exdb/mnist/).  
Achieves **~97.81% accuracy** on the test set.

[click here](https://pytorch-mnist-classifier-7mbzakcfmypleksqrkfweu.streamlit.app)


---

## 📌 Overview
This project demonstrates how to:
- Load and preprocess the MNIST dataset with **TorchVision**
- Build a neural network with **PyTorch**
- Train, validate, and evaluate the model
- Save and load trained models
- Perform inference on new handwritten digit images

Perfect for beginners who want to learn **image classification** in PyTorch.

---

## 🚀 Features
- **End-to-end training pipeline** (data loading → training → evaluation)
- **GPU/CPU support**
- **Configurable hyperparameters**
- Easy **model saving/loading**
- Clean and beginner-friendly PyTorch code
